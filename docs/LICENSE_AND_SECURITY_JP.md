## 問題を見つけた方へ

未修正の脆弱性、攻撃手順、秘密鍵、access token、個人情報を公開Issueへ書かないでください。
公式リポジトリの[非公開脆弱性報告窓口](https://github.com/MIN0/min0-core-forth/security/advisories/new)を
使用してください。問題の発見は、実装と資料を改善するための大切な成果です。

## Forkと再配布

- `LICENSE`の著作権表示と許諾表示を残す。
- 改造版であることを明記し、独自のbuild名またはversion suffixを付ける。
- 原版の監査結果を、変更後のコードにも自動的に成立する証拠として扱わない。
- 追加した第三者素材の権利と表示条件を確認する。
- 実機用の秘密鍵をrepository、配布ZIP、test fixtureへ入れない。
