# なぜMIN0 CORE FORTHをRubyとPythonで始めたのか

MIN0 CORE FORTHは、特定のCPU、MPU、OSに最初から結び付けず、さまざまな実装の母体に
なれるFORTHを実験することから始まりました。将来の対象は小規模なマイコンやFPGAを中心に
考えていますが、最初の段階では命令セットやメモリ容量に発想を縛られないことを重視しました。

そこで、実機向けコードを書く前の「実行できる仕様」としてRuby版とPython版を並行して作りました。
この二つは最終ターゲットではありません。同じFORTHの意味を異なる二つの言語で表現し、結果を
照合することで、一方の実装だけでは見落としやすい曖昧さ、思い込み、移植時の問題を早い段階で
見つけるための実験台です。ハードウェアの制約を入れる前に自由に試し、その後で小型化、高機能化、
新しいCPUへの移植など、目的に応じて枝を伸ばせる「根」を作ろうとしています。

Rubyを選んだ背景には、開発者自身の経験もあります。1980年代後半に80386のアセンブラで
ファームウェアを開発した時期があり、その後は長くプログラミングから離れていました。のちに趣味で
Rubyを使ってExcelファイルを組み換えたとき、かつての厳しい制約とは違い、発想をそのままコードにし、
すぐ動かして確かめられる楽しさを改めて感じました。一方、現在の実験環境を考えるうえでPythonも
欠かせません。RubyとPythonにはそれぞれ異なる読みやすさと強みがあり、その違いが相互検証を支えて
います。

したがって、この二言語版の目的は「RubyかPythonのどちらかを選ぶ」ことではありません。二つの
独立した実装を鏡として使い、FORTHの共通部分を観察し、将来の実機版に持ち込むべき仕様を育てること
です。MIN0 CORE FORTHは、完成した一台の計算機ではなく、さまざまな方向へ根を伸ばすための実験から
始まっています。

この文章はプロジェクトの背景説明です。FORTH2020などで紹介する際には、発表時間や聞き手に合わせて
短縮し、実演と組み合わせて使用できます。
