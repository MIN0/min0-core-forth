# なぜMIN0 CORE FORTHをRubyとPythonで始めたのか

[英語版はこちらです](PROJECT_ORIGIN.md)

MIN0 CORE FORTHは、特定のCPU、MPU、OS、メモリ容量に最初から結び付けず、さまざまな実装の母体に
なれるFORTHを実験することから始まりました。将来は小規模なマイコンやFPGAを中心に考えていますが、
最初の段階では対象命令セットに発想を早く縛られないことを重視しました。

そこで、実機コードを書く前の「実行できる仕様」としてRuby版とPython版を並行して作りました。
二つは最終ターゲットではありません。同じFORTHの意味を異なる言語で独立して表現し、結果を照合する
ことで、一方だけでは見落としやすい曖昧さ、思い込み、移植上の問題を早く発見します。

Rubyには開発者自身の経緯もあります。1980年代後半に80386アセンブラでファームウェアを開発した後、
長くプログラミングから離れていました。後にRubyでExcelファイルを組み換えたとき、発想をすぐコードに
して確かめる楽しさを再び感じました。現在の実験にはPythonも欠かせません。両者の異なる読みやすさと
強みが、相互検証を支えています。

目的はRubyとPythonの勝者を決めることではありません。二つの実装を鏡として使い、共通するFORTHの
意味を観察し、将来の実機へ持ち込む仕様を育てることです。MIN0 CORE FORTHは完成した一台の計算機では
なく、多くの実装へ根を伸ばすための実験から始まっています。

この文章は背景説明です。FORTH2020などで紹介するときは、発表時間と聞き手に合わせて短くし、実演と
組み合わせて利用できます。
